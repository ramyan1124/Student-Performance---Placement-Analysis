# 🎓 Student Performance & Placement Analysis

## 📌 Project Overview

This project analyzes student placement data using Python to identify patterns in courses, branches, recruiting companies, job roles, salary distribution, and placement locations.

The analysis was performed using Pandas, NumPy, Matplotlib, and Seaborn to clean, explore, analyze, and visualize the dataset.

## 🎯 Objectives

- Analyze student distribution across courses and branches
- Understand company-wise placement patterns
- Analyze job role distribution
- Study salary distribution and salary variations
- Compare average salary across courses, branches, companies, and locations
- Identify placement trends over time
- Explore the relationship between courses and job roles
- Identify the highest salary records in the dataset

## 🔍 Key Insights

- The dataset contains 1,000 student placement records.
- The average salary is approximately ₹7.40 lakh.
- The median salary is approximately ₹7.46 lakh.
- BA is the most represented course in the dataset.
- EEE is the most represented branch.
- IBM is the most common recruiting company.
- Support Engineer is the most common job role.
- Salaries range from approximately ₹3.01 lakh to ₹11.98 lakh.
- Bangalore is the most common placement location in the dataset.

## 📝 Conclusion

This project demonstrates how Python-based data analysis can be used to explore student placement data and identify meaningful patterns across academic background, job roles, companies, salaries, and locations.

The analysis provides a structured understanding of placement records and salary patterns using data cleaning, exploratory data analysis, statistical analysis, and data visualization techniques.
